# DLSS5 Neural Render v0.1.24

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

Rust + Tauri v2 で構築した、DLSS Neural Rendering のデスクトッププレビューおよび書き出しツールです。

## プレビュー

![DLSS5 Neural Render の UI](Preview.jpg)

## 最新バージョン

通常の利用では自分でコンパイルする必要はありません。[Releases](https://github.com/JDui/GUI-DLSS5/releases)
から Windows x64 パッケージをダウンロードして展開し、`run.bat` を実行してください。
パッケージにはアプリ本体、DLSS ランタイム、FFmpeg、FFprobe が含まれています。NVIDIA GeForce
RTX 50 / 40 / 30 シリーズに対応しています。

## ビルド

```powershell
cargo build --release --manifest-path src-tauri\Cargo.toml
```

実行ファイルは `src-tauri\target\release\dlss5-tauri.exe` に生成されます。プロジェクトの
ルートにある `run.bat` を実行すると、必要に応じて Release ビルドを行い、ホスト DLL と選択した
RTX ランタイムを正しく見つけられるよう作業フォルダーも設定します。

## 内蔵ランタイム

- `nvngx_dlssnr.dll`：RTX 50 ネイティブランタイム
- `nvngx_dlssnr_40.dll`：RTX 40 互換ランタイム
- `nvngx_dlssnr_30.dll`：RTX 30 互換ランタイム

起動時に RTX 30 / 40 / 50 シリーズを自動判定し、対応するランタイムを選択します。判定できない
場合は RTX 50 を標準で使用し、手動で変更できます。NGX セッションはプロセス単位で作成されるため、
ランタイムを変更した場合はアプリを再起動してください。

## 対応言語

起動時はコンピューターの言語が中国語・英語・日本語のいずれかであれば、その言語を自動選択します。
それ以外のシステム言語では中国語にフォールバックします。ウィンドウ上部の薬丸型スイッチで、
中文・English・日本語をいつでも切り替えられます。選択した言語は次回起動時にも保持されます。

## 操作

- ファイル選択、ドラッグ＆ドロップ、クリップボードから画像や動画を読み込めます。
- PNG、JPG、GIF、MP4、AVI、MOV、MKV などに対応しています。GIF はプレビューと書き出しの前に
  `Temp` フォルダーへ MP4 キャッシュとして変換されます。
- 動画プレビューは常駐の順次デコーダーと直近フレームキャッシュを使用します。再生が遅れた場合は
  タイムラインに追従するためフレームをスキップし、FFmpeg / FFprobe はバックグラウンドで静かに動作します。
- プレビューは長辺 4520 ピクセルまでです。画像と動画の書き出しは指定した出力サイズ（標準は元画像サイズ）
  を使用し、X1 / X2 / X4 ボタンで倍率を設定できます。
- 右側には DLSS パラメータ、アップスケール、後処理、エンコーダーのタブがあります。
- マルチパスは 1～5 回の DLSS 処理に対応します。実際に拡大する場合の順序は、DLSS 1 回目 →
  RTX VSR 1 回 → 残りの DLSS Pass です。Pass 数が多いほどノイズが大きくなる場合があります。VSR は
  緩和できますが、完全には除去できません。
- アップスケールには RTX VSR が必要です。RTX 20 シリーズ以上、550 以上のドライバー、プログラム
  フォルダー内の `nvngx_vsr.dll` と `rtx_vsr_host.dll` が必要です。VSR が利用できない場合、
  アップスケールは無効になり、元解像度を超えて書き出すことはできません。
- エンコーダータブでは NVENC または CPU の x264 / x265 で H.264 / H.265 を選択できます。CQ / CRF は
  数値が低いほど高画質です。H.265 / HEVC NVENC Lossless は QP 0 と 4:4:4 RGB ピクセル形式の
  ロスレス映像出力として利用できます。NVENC が利用できない場合は x265 のロスレスモードに
  フォールバックします。「音声を保持」を有効にすると、元動画の音声トラックを AAC に変換して付加するため、
  音声自体はロスレスではありません。
- クイック比較、比較、AB ビューを利用できます。クイック比較では左ボタンを押して元画像を確認し、比較では
  分割線をドラッグします。中 / 右ボタンで移動し、ホイールでポインターを中心にズームできます。

## 書き出し

保存先を選択すると、現在のビュー、DLSS 画像、または DLSS 動画を書き出せます。配布パッケージには
FFmpeg / FFprobe が含まれているため、動画と GIF をそのまま処理できます。ソースから起動する場合は、
FFmpeg / FFprobe を `PATH` から利用できるようにしてください。

起動時に前回の `Temp` 内容を削除し、通常終了時には今回の一時キャッシュも削除します。
